# Financial complaints Analysis based on Service Performance and Disputes Resolution



## 

## Problem Statement



Financial institutions like banks and mortgage companies receive thousands of complaints by the consumers ranging from credit/debit disputes along with several types of mortgage disputes. Without having a structured analytics tracking, organizations will struggle in identifying the root cause of these problems, they also face the challenge of complaints piling up without timely resolution which negatively affects customer retention and satisfaction and also promotes to an increase in operational costs.



#### Key Goals:



* Transform raw consumer dispute records into actionable operational intelligence.
* Help financial institutions to pin-point products that are high risk
* Optimize the response timeline
* Provide actionable insights for future disputes resolution





#### Key Areas of Analysis



* Quantify resolution efficiency
* Analyze issue root cause
* Isolating top causes for maximum complaints
* Company's ability to handle grievances in a timely and effective manner.





#### Tools Used



* Microsoft Excel- Initial data cleaning \& making calculated fields for analysis
* Microsoft SQL Server- Data Extraction, analysis, summarizations and report building
* Microsoft Power BI - Dashboard building





#### Deliverables



* Strategic recommendations for future grievances.
* SQL Queries for the analysis.
* Dashboard Screenshots
